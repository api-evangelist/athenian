# Athenian

> Athenian was a full-cycle software-development analytics platform (founded 2019, CEO Eiso Kant; seed led by Point Nine). It integrated GitHub, JIRA, and CI/CD to give engineering leaders end-to-end delivery metrics focused on teams and events rather than individuals. The company has since wound down — athenian.com and athenian.co now redirect to github.com/athenianco and api.athenian.co no longer resolves — but the OpenAPI specification and open-source code remain published on GitHub (athenian-api-open, MIT).

## API
- Athenian API (OpenAPI 3.0.3, v2.1.86): https://github.com/athenianco/api-spec — 79 operations across metrics, filters, histograms, events, settings, teams, and repository sets. Production server (offline): https://api.athenian.co/v1
